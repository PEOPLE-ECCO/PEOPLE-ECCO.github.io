# PEOPLE-ECCO Solutions Handbook

Welcome to the PEOPLE-ECCO solutions handbook!

This handbook is designed to support NGO's/CSO's active in ecosystems conservation, and other potential users, in applying the Earth Observations solutions developed during the [PEOPLE-ECCO](https://www.people-ecco.eu/) project.

For each solution, the handbook lists:

- **Theoretical background**: to understand why the solution was developed and what goes on under the hood.
- **Key considerations**: to highlight some of the choices users have to make when applying the solutions in their own work
- **Getting started**: practical use of the solution

##  Terrestrial solutions

The development of the terrestrial solutions was led by [Hatfield](https://hatfieldgroup.com/). Source code of the terrestrial solutions can be found in **[this](https://github.com/PEOPLE-ECCO/ecco-terrestrial-solutions)** GitHub repository. Please use the repository's **[issues](https://github.com/PEOPLE-ECCO/ecco-terrestrial-solutions/issues)** tab to report bugs or suggest improvements. 

The PEOPLE-ECCO terrestrial solutions are:

- [Best Available Pixel compositing](terrestrial-solutions/best-available-pixel/getting-started/): Create a single image composite from all data available within a pre-defined time window
- [Vegetation Productivity Trend](terrestrial-solutions/VPT/getting-started/): Apply the Spectral Recovery or Seasonal Sen's Slope algorithm to monitor gradual vegetation change
- [Vegetation Disturbance Occurrence](terrestrial-solutions/disturbance-occurrence/getting-started/): Detect abrupt vegetation disturbance signals feom multi-year time series
- [Habitat Disturbance Rating](terrestrial-solutions/habitat-disturbance/getting-started/): Integrate multiple datasets into a single score to quantify habitat disturbance

The PEOPLE-ECCO aquatic solutions are:

-[Submerged Aquatic Vegetation and coral reef extent](marine-solutions/SAV/getting-started): Use a machine learning model to map seagrass and coral reef extent
-[Habitat connectivity](marine-solutions/habitat-connectivity/getting-started)
-[Habitat frequency](marine-solutions/habitat-frequency/getting-started)

##  Effectiveness solution
The development of the effectiveness solution was led by [ITC](https://www.utwente.nl/en/itc/). Source code of the effectiveness solution can be found in **[this](https://github.com/PEOPLE-ECCO/ecco-effectiveness-solutions)** GitHub repository. Please use the repository's **[issues](https://github.com/PEOPLE-ECCO/ecco-effectiveness-solutions/issues)** tab to report bugs or suggest improvements. 

The PEOPLE-ECCO effectiveness solution is:

-[Before-After-Control-Impact assessment](effectiveness-solutions/BACI/getting-started): Identify control sites through statistical matching and use them to assess conservation action effectiveness.
